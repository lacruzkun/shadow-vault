A random number is a value drawn from a sequence in which no value can be predicted from the values that came before it, and in which every value in the defined range has an equal chance of occurring.

Monte Carlo simulation: a technique where repeated random sampling is used to estimate numerical results

### Properties of a Good sequence of Random Number

- Uniformity
- Independence
- Period
- Efficiency
- Reproducibility


### Testing Random Numbers
- Chi-square test
- Kolmogorov-Smirnov (K - S) test

## Types of Random Numbers

**True Random Numbers**: these numbers are generated from unpredictable physical processes like atmospheric pressure, quantum levels, radioactive decay and so on. They can't be readily reproduced so they are used in cryptography and other fields that need absolute security, But it's not good for things like simulation where we want to reproduce the simulation on the same random numbers
