# System

Ok from my understanding system is a collection of related components working together to achieve a specific objective on the environment.

Contrast with the book

>A system is an organized collection of interacting, interrelated, and interdependent components that work together to achieve a specific objective, within a defined boundary, and interacting with its environment.


## Characteristics of a system
- Organization
- Interaction
- Interdependance
- Integration
- Objective

## Model

A model is a simplified representation of a system envisioned to establish a transparent understanding of the system.
In my own words it's like a stripped down version of the system into the bare essentials needed for understanding the system.

### Types of Models

- Physical Model
- Scaled Model
- Analog Model
- Schematic model
- Management model
- Simulation
- Mathematical Model
- Heuristic Model

## Modelling

#modelling is the process of creating or developing a representation of reality to help in understanding, analysis, or prediction of the real entity. 
Just say its the process of creating the model. as we mentioned above 'Model' is a representation only a representation.

## Simulation

A #simulation is a technique for representing a dynamic real-world system by a model and experimention with the model to gain information about the system and therefore take appropriate decision.

ok think of a simulation like this: it takes the real world representation (which is the model) and then uses that to play out in real-time how the components will react to each other. That's what it is at the core

### Uses

- Cost and safety
- Time compression
- Study systems that don't exist yet
- Risk free experimentation
- Understanding complex interactions
- Training
- Forecasting system behaviours
